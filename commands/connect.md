---

Load the `pixy` skill (from this plugin) and run its **Connect** flow: read
`.claude/pixy.json` (run the Setup flow first if it's missing), ensure the
dev server, open the page, then enter the `pixy_wait` loop and stay in it
until the session ends. The user is switching to the browser now; keep the
terminal quiet while the session is live.
